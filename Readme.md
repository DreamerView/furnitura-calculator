## Запуск

```bash
php -S 127.0.0.1:8080 router.php
```

или `start.bat`, затем `http://127.0.0.1:8080/`.

На чистой установке первым открывается `#/setup`. После создания Central калькулятор публичный: ассортимент и расчёт доступны без авторизации, реальные цены сервер отдаёт только авторизованной ветке с эффективным `price_access`.

## SPA

- `#/calculator` — калькулятор;
- `#/users` — управление Central/Dealer/Subdealer;
- `#/advertising` — управление рекламным изображением в Vue (только Central);
- `#/login` — вход или активация Client;
- `#/setup` — первый Central.

Навигация работает через RouterLink/RouterView без перезагрузки документа. Central открывает HTML-конструктор кнопкой «Настройка калькулятора» в отдельной именованной вкладке; повторное нажатие возвращает в ту же вкладку.

## Языки

Интерфейс поддерживает:

- Русский;
- English;
- Türkçe.

Язык выбирается в header/экранах SPA и сохраняется локально в IndexedDB. Переключение языка не перезагружает страницу.

## Дизайн

Central может выбрать глобальный стиль интерфейса в `Управление → Дизайн`:

- `Default` — основной дизайн WorkDesk;
- `Soft` — WorkDesk с более округлыми группами;
- `Easy` — WorkDesk с увеличенными полями;
- `Glossy` — мягкий вариант WorkDesk;
- `Material` — WorkDesk с компактными радиусами.

Выбранная тема хранится на сервере и применяется всем пользователям. До её загрузки рабочий DOM закрыт preloader, поэтому промежуточные темы не показываются.

## Пользователи и иерархия

- Central создаёт только корневой Dealer.
- Dealer создаёт Subdealer или Client непосредственно под собой.
- Subdealer создаёт Subdealer или Client непосредственно под собой.
- Client не имеет управления пользователями.
- Родитель определяется сервером автоматически.
- Создание/редактирование — через modal; удаление — через отдельное подтверждение.

## Client: ключ → регистрация → вход

Секретный ключ Client больше **не является авторизацией**.

1. Dealer/Subdealer создаёт Client и получает `FTR-XXXX-XXXX-XXXX-XXXX`.
2. Client выбирает **«Активация по ключу»**.
3. Вводит секретный ключ.
4. Обязательно создаёт уникальные логин и пароль.
5. Только после регистрации возникает обычная Client-сессия и может открыться доступ к ценам — если `price_access` разрешён всей родительской цепочкой.
6. Следующие входы выполняются по логину и паролю.

Перевыпуск ключа непосредственным Dealer/Subdealer сбрасывает Client-регистрацию и требует повторной активации.

## Уникальность логинов

Логины глобально уникальны для Central, Dealer/Subdealer и Client, регистр не учитывается: `Admin`, `admin`, `ADMIN` конфликтуют.

Backend повторно проверяет уникальность при:

- первом создании Central;
- создании Dealer/Subdealer;
- редактировании Dealer/Subdealer;
- активации Client.

UI дополнительно показывает живой статус **«Логин доступен» / «Логин уже занят»**. Серверная проверка остаётся окончательной.

## Каталог и цены

Каталог хранится в `storage/state.json`, а сами фото — отдельными файлами в закрытой серверной папке `storage/product-photos`. Central редактирует комплектации и артикулы в отдельной вкладке HTML-конструктора; рекламное изображение настраивается в Vue по маршруту `#/advertising`. Загрузка и удаление фото из конструктора и базы артикулов калькулятора выполняются защищённым API. Локальные фото не подмешиваются в каталог. Публичный пользователь получает цены как `0`.

`effective_price_access = price_access(self) AND price_access(parent) AND …`

## Excel

SheetJS разрешён через CDN, но не блокирует первый рендер. После `window.onload` приложение в фоне вызывает общий lazy loader:

`https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js`

Все Excel-действия используют один Promise и повторно библиотеку не загружают в рамках страницы.

### Дополнения 2026.10.08.6
В калькуляторе и конструкторе вид цапфы выбирается тремя изображениями без подписей; название доступно при наведении. Выбор сохраняет существующие рецепты, неподдерживаемые сочетания отключены. Для поворотных створок в опциях доступны подтверждённые варианты петлевой группы. Подкладка скрытой петли определяется профилем; объединённый Deceuninck/Thyssen требует уточнения схемы. Нагрузки и прижимы проверяются по монтажной документации.
В заголовках категорий цен доступны переименование и удаление собственных категорий. Перед удалением требуется выбрать замену либо наследование; несохранённые изменения сначала сохраняются. Последняя категория сохраняется. В оптовых заявках артикул и наименование разделены.
